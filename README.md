# Mini Semantic Search Lab

A lightweight semantic search engine built using Pandas, ChromaDB, and Sentence-Transformers to query FAQs based on meaning rather than exact keywords.

## Deliverables
- `mini_semantic_search.ipynb`: Jupyter/Colab notebook containing the end-to-end pipeline.
- `faqs.csv`: Sample FAQ dataset.
- `requirements.txt`: Project dependencies.

## Example Queries & Results

* **Query:** `"I forgot my login credentials"`
  * **Top Match:** How do I reset my password?
  * **Answer:** Go to settings and click 'Reset Password' to receive an email link.
